## Planejamento
# DeCode — Ferramentas de Criptografia e Conversão Online

O **DeCode** é um conjunto de ferramentas online para **criptografia, conversão, formatação e codificação**, tudo feito **100% no frontend**, sem enviar nenhum dado para servidores externos.

Rápido, intuitivo, minimalista — criado para devs e curiosos que precisam transformar texto **de forma segura e instantânea**.

---

## Funcionalidades Principais

O projeto inclui (ou incluirá) diversas ferramentas úteis:

### **Criptografia & Codificação**
- Base64 Encode/Decode  
- URL Encode/Decode  
- ROT13 / ROT47  
- Cifra de César  
- Cifra de Vigenère  
- Morse Code  
- Base32  
- Texto invertido / espelhado  

### **Ferramentas para Devs**
- JSON Formatter  
- XML Formatter  
- Conversor CSV ↔ JSON  
- Minify/Beautify de HTML, CSS e JS  
- Conversão de cores (HEX ↔ RGB ↔ HSL)  
- Gerador de Hash (MD5 / SHA256)  

Todas essas operações são executadas diretamente no navegador usando **JavaScript puro**, garantindo performance e privacidade.

---

## Por que esse projeto existe?

Ferramentas de criptografia e conversão na internet costumam ser:

❌ lentas  
❌ cheias de anúncios  
❌ feias  
❌ não responsivas  
❌ inseguras (enviam dados para backends)

O **DeCode** nasceu para ser o oposto:

✔ rápido  
✔ clean  
✔ responsivo  
✔ seguro  
✔ open-source

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3 (Flexbox + Grid)**
- **JavaScript puro**
- **Hospedagem estática (Vercel / GitHub Pages)**

Nenhum backend é necessário — tudo roda diretamente no navegador do usuário.
